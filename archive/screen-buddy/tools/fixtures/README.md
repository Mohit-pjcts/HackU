# Fixtures for the Brain Lab

Four screenshots of the real Photopea editor (1366x768 and 1920x1080, default screen and with the Select menu open) and `labels.json` with 33 target boxes, generated by `tools/autolabel/autolabel.mjs` on Fri 2 Oct 2026. The boxes come from Photopea's own page structure, not from hand-drawing.

Use them to try the lab without making screenshots first: open `/tools/brain-lab.html`, pick all five files at once, choose a mode, press **Run on this image** or **Run batch**.

These are scripted states, not real user sessions. They show whether the model can find a control at a given size. They do not replace hand-labelled screenshots from real trials; report the two separately.

The photo inside the editor is NASA image S90-38573 (astronaut Frank Culbertson), from images-api.nasa.gov, used only as the cut-out demo image. It is a real, identifiable person: do not imply NASA or the person endorses the project. Photopea's own "Support Photopea" panel appears in the 1366 and 1920 screenshots, as it does in the live embed.
